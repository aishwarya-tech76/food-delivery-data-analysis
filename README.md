# 🍔 Food Delivery Data Analysis Dashboard

An interactive data analytics project built using **Python, Pandas, Plotly, SQL, and Streamlit** to analyze food delivery orders and generate actionable business insights.

👉 [**Click here to explore the live dashboard**](https://food-delivery-data-analysis-agwhe4rsavyyktxgukaz5q.streamlit.app/)

## 💻 GitHub Repository

👉 [View Source Code on GitHub](https://github.com/aishwarya-tech76/food-delivery-data-analysis)

## 📊 Project Overview

This project analyzes a dataset of 1,000 food delivery orders to understand sales performance, customer preferences, restaurant performance, payment methods, and delivery operations.

The interactive dashboard helps users explore business performance through charts, KPIs, filters, and data-driven insights.

## ✨ Key Features

- Interactive filters for city, category, payment mode, and order status
- Business overview with key performance indicators (KPIs)
- Category-wise sales analysis
- Monthly sales trend analysis
- Top 5 restaurants and food items by sales
- Payment mode and order status distribution
- City-wise and day-wise sales analysis
- Delivery time and customer rating analysis
- Top 5 customers by purchase value
- Dataset preview and business recommendations

## 🛠️ Tools & Technologies

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Plotly
- **Dashboard:** Streamlit
- **Database Queries:** SQL
- **Notebook Environment:** Jupyter Notebook

## 📈 Key Business Insights

Based on the analysis of 1,000 food delivery orders:

- **Total Orders:** 1,000
- **Gross Order Value:** ₹6,17,576
- **Total Quantity Sold:** 2,533
- **Average Order Value:** ₹617.58
- **Top Sales Category:** Pizza — ₹1,35,183
- **Top-Selling Food Item:** Paneer Pizza — ₹44,264
- **Most-Used Payment Mode:** UPI — 351 orders
- **City with Highest Order Count:** Nagpur — 215 orders
- **Average Delivery Time:** Approximately 42 minutes
- **Order Cancellation Rate:** 23.8%
- **Average Customer Rating:** 4.01/5
- **Highest Sales Month:** September — ₹63,446

## ▶️ Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/aishwarya-tech76/food-delivery-data-analysis.git
cd food-delivery-data-analysis
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Launch the dashboard

```bash
streamlit run dashboard/app.py
```
